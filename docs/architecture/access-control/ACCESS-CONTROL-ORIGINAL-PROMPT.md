ما در حال توسعه پروژه tarkhineh-backend هستیم.

لطفاً قبل از پاسخ‌دادن، سه سند زیر را به‌دقت مطالعه کن:

1. MASTER-ARCHITECTURE.md
2. IMPLEMENTATION-STATUS.md
3. ARCHITECTURAL-DECISIONS.md

این سه سند مرجع اصلی پروژه هستند.

قوانین همکاری:

- معماری تأییدشده را دوباره از ابتدا طراحی نکن.
- Phaseهای تکمیل‌شده را تکرار نکن.
- وضعیت واقعی Repository را بر اساس اسناد و کد فعلی بررسی کن.
- فقط روی Phase فعال‌شده کار کن.
- قبل از تغییر کد، فایل‌های واقعی مرتبط را بررسی کن.
- دستورات Terminal را یکی‌یکی ارائه بده و بعد از بررسی خروجی، دستور بعدی را بده.
- هیچ تست، Migration یا Build را بدون مشاهده نتیجه موفق اعلام نکن.
- در پایان هر جلسه IMPLEMENTATION-STATUS.md را به‌روز کن.
- از تغییر تصمیمات معماری بدون ارائه دلیل و تأیید من خودداری کن.
- Clean Architecture، DDD، Separation of Concerns و جلوگیری از Overengineering را رعایت کن.

ابتدا وضعیت فعلی پروژه را از روی اسناد خلاصه کن و دقیقاً مشخص کن در کدام Phase هستیم و قدم بعدی چیست.

تا زمان تأیید من، تغییر کدی انجام نده.
